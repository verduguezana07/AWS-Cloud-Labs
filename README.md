# AWS Cloud Labs ☁️

Laboratórios práticos realizados durante minha jornada de estudos em **Cloud Computing, AWS e Linux**.

Este repositório reúne meus principais laboratórios, organizados por serviço e em ordem de aprendizado, com documentação, evidências e principais aprendizados.

## 📚 Laboratórios

### 01 — AWS CloudFormation

Laboratórios relacionados à criação e gerenciamento de infraestrutura utilizando CloudFormation.

### 02 — Amazon EC2 e EBS

Laboratórios envolvendo instâncias EC2, armazenamento EBS, volumes, snapshots e gerenciamento de armazenamento.

### 03 — Amazon S3

Laboratórios envolvendo buckets, objetos, hospedagem de sites estáticos, versionamento e notificações.

### 04 — Amazon RDS

Laboratórios relacionados a bancos de dados relacionais e migração de aplicações para Amazon RDS.

### 05 — Amazon Route 53

Laboratórios relacionados a DNS, Health Checks, Failover e alta disponibilidade.

### 06 — AWS Lambda

Laboratórios relacionados a funções serverless e integração com outros serviços AWS.

---

## 🎯 Objetivo

Documentar minha evolução prática em **AWS, Cloud Computing e Linux**, transformando os laboratórios realizados durante meus estudos em projetos organizados para meu portfólio profissional.
